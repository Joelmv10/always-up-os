# 07-automations

Scripts e integraciones (Airtable, email, WhatsApp) para automatizar procesos.

## Materiales de venta y propuestas
- `materiales/` — genera fichas Team/Coach, deck de empresa (completo y público) con marca. Ver `02-sales/guia-materiales.md`.
- `propuestas/` — genera propuestas escritas por servicio a partir de una ficha JSON. Ver `02-sales/propuesta-template.md`.

## Outreach (octubre 2026)
`outreach/generar_outreach.py` genera la hoja "Outreach - Copiar y pegar" del CRM y `02-sales/outreach-textos-generados.md`. Plan completo: `02-sales/plan-outreach-30-dias.md`.
